📊 FinanceTracker

A simple and interactive personal finance tracker web app built with Hugging Face Spaces. FinanceTracker helps users manage budgets, track expenses, visualize spending, and plan savings—all from an intuitive dashboard.

🚀 Features

Dashboard Overview – View summary of income, expenses, and balance
Add / Edit Transactions – Record expenses and incomes with categories
Budget Planner – Set budgets for different categories and track progress
Spending Insights – Visual charts showing spending patterns
Easy Export – Export data in CSV/Excel formats (future feature)
Responsive UI for desktop and mobile

💡 Why FinanceTracker?

FinanceTracker gives you a quick way to manage your personal finances without complicated tools. It’s great for:
Tracking monthly expenses
Setting realistic budgets
Keeping financial goals in check
Understanding where your money goes

🧠 How It Works

Enter Transaction Details – Add income or expense with category and amount
Monitor Your Budget – See if you’re staying within limits
Visualize Data – Graphs and charts update as you add transactions
Plan Ahead – Use insights to adjust your spending habits
